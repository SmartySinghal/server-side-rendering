Home (Prerendered at build time)

This page uses RenderMode.Prerender. Its HTML was created once, when you ran npm run build, and saved as a file. Every visitor gets that same file, so the time shown above stays the same until you build again.

1. Event replay

Clicks made before JavaScript finishes loading are recorded and replayed after hydration (withEventReplay()), so nothing is lost.

2. Browser-only APIs

window does not exist on the server. This value is read inside afterNextRender(), which only runs in the browser:
